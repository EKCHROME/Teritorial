# Teritorial

A browser-based territory conquest game built with TypeScript and Vite.

## Run

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Click or drag from one of your cells to an adjacent enemy or neutral cell to attack.

## Controls

- **Left drag / click:** select a friendly cell and attack an adjacent cell
- **Pause:** stop army growth and AI movement
- **Restart:** generate a new match
